# MyProject Toolkit 🚀

High-performance, modular TypeScript library providing fundamental algorithms, cryptography, collections, and Web3 utility primitives.

## Features
- **Cryptography:** Merkle Trees, SHA-256, Keccak-256, Poseidon, HMAC.
- **Data Structures:** LRU/LFU Cache, Ring Buffer, Trie, Bloom Filter, Priority Queue.
- **Network Primitives:** RPC Client, Circuit Breaker, Exponential Backoff.
- **Performance:** Zero external runtime dependencies, sub-millisecond execution.

## Installation
```bash
npm install myproject-toolkit
```
